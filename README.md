# 🚨 Emergency Response System for Disaster Management with Multilingual AI Chat Support

An AI-powered multilingual emergency response platform designed to assist users during disasters and emergency situations through real-time chat support, intelligent incident detection, and live emergency service mapping.

---

## 📌 Features

- 🌐 Multilingual AI Chat Support
- 🤖 AI-based Emergency Intent Classification
- 📍 Live Map Integration for Nearby Hospitals & Police Stations
- 🔐 Secure User Authentication
- 📊 Analytics Dashboard
- ⚡ Real-Time Emergency Assistance
- 🧠 NLP-Based Response Generation
- 📱 Responsive Web Interface

---

## 🛠️ Tech Stack

| Category | Technology |
|---|---|
| Frontend | HTML, CSS, JavaScript |
| Backend | Python Flask |
| Database | Firebase / PostgreSQL |
| Authentication | Firebase Authentication |
| Machine Learning | Naïve Bayes / Logistic Regression |
| NLP | Tokenization, TF-IDF |
| Translation | Google Translate API |
| Maps | Google Maps API |
| Analytics | Pandas, Matplotlib |

## 📂 Project Workflow

### 🔹 Pre-Emergency Phase
- Safety guidelines
- Awareness tips
- Preparedness training

### 🔹 During-Emergency Phase
- User login & language selection
- Emergency incident reporting
- AI intent classification
- Real-time multilingual response
- Live emergency service mapping

### 🔹 Post-Emergency Phase
- Recovery guidance
- Medical & psychological support
- Data storage for analytics

---

## 🧠 Machine Learning Pipeline

1. User Input  
2. Language Detection  
3. Translation to English  
4. Text Preprocessing  
5. Feature Extraction (TF-IDF)  
6. Intent Classification  
7. Response Generation  
8. Translation to User Language  
9. Live Map Update

```bash

# Navigate to project directory

# Install dependencies
pip install -r requirements.txt

# Run the Flask server
python app.py
```
